# Cognifyz Data Science Internship

A collection of data analysis and data science projects completed during my Data Science Internship at Cognifyz IT Solutions Pvt. Ltd.

## About the Internship

This repository contains my work across Level 1 and Level 2 of the Cognifyz Data Science Internship.

The projects focus on exploring, analyzing, visualizing, and engineering features from a restaurant dataset using Python.

## Dataset

The projects use a restaurant dataset containing information such as:

- Restaurant details
- Location information
- Cuisines
- Aggregate ratings
- Votes
- Price range
- Table booking availability
- Online delivery availability

## Level 1 — Data Analysis

### Task 1 — Data Exploration and Preprocessing

- Explored the number of rows and columns.
- Checked missing values.
- Performed data type conversion where required.
- Analyzed the distribution of the Aggregate Rating variable.

### Task 2 — Descriptive Analysis

- Calculated basic statistical measures such as mean, median, and standard deviation.
- Analyzed categorical variables including Country Code, City, and Cuisines.
- Identified the top cuisines and cities with the highest number of restaurants.

### Task 3 — Geospatial Analysis

- Visualized restaurant locations using latitude and longitude.
- Analyzed restaurant distribution across cities and countries.
- Studied the relationship between restaurant location and rating.

## Level 2 — Advanced Data Analysis

### Task 1 — Table Booking and Online Delivery

- Calculated the percentage of restaurants offering table booking.
- Calculated the percentage of restaurants offering online delivery.
- Compared average ratings of restaurants with and without table booking.
- Analyzed online delivery availability across different price ranges.

### Task 2 — Price Range Analysis

- Determined the most common restaurant price range.
- Calculated average ratings for each price range.
- Visualized the average ratings and identified the color representing the highest average rating.

### Task 3 — Feature Engineering

- Extracted Restaurant Name Length as a new feature.
- Extracted Address Length as a new feature.
- Encoded Has Table Booking as a numerical feature.
- Encoded Has Online Delivery as a numerical feature.
- Generated summary statistics for the engineered features.
