# Level 2 — Task 2: Price Range Analysis

## Internship

Cognifyz Data Science Internship

## Task

Price Range Analysis

## Objective

The objective of this task is to analyze restaurant price ranges and understand their relationship with restaurant ratings.

The analysis focuses on:

- Determining the most common price range among restaurants.
- Calculating the average rating for each price range.
- Identifying the color representing the highest average rating.

## Analysis Performed

### 1. Most Common Price Range

The number of restaurants in each price range was calculated using value counts.

The most frequently occurring price range was identified from the dataset.

### 2. Average Rating by Price Range

The average `Aggregate rating` was calculated for each `Price range`.

This helps compare restaurant ratings across different price categories.

### 3. Highest Average Rating

The price range with the highest average restaurant rating was identified.

A bar chart was created using different colors for each price range, allowing the color associated with the highest average rating to be identified.
